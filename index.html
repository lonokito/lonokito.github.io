Lonokito Studio

Lonokito Studio es una herramienta privada de escritorio que produce videos educativos cortos con Lonokito, un pichón animado de traje negro, y los sube a las cuentas propias de su dueño en YouTube (canal Lonokito_) y TikTok.

Lonokito Studio is a private desktop tool that produces short educational videos starring Lonokito, an animated pigeon in a black suit, and uploads them to its owner's own YouTube channel (Lonokito_) and TikTok account.

Developed with YouTube – Lonokito Studio usa los Servicios de API de YouTube / uses YouTube API Services.
